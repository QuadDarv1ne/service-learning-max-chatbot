## [1.7] — 2026-09-24

### Добавлено — расширенные возможности команд для бота
- ✨ **Новая модель `BotCommand`** в Prisma (id, name, description, type, response, faqId, enabled, order)
  - Поле `type`: `text` (статичный ответ) | `faq` (ссылка на конкретный FAQ) | `function` (встроенный обработчик)
  - Поле `response` для type='text' — текст, который получит пользователь
  - Поле `faqId` для type='faq' — указывает на конкретный ответ из базы
  - Уникальный `name`, индексы на `enabled` и `name`
- ✨ **CRUD API для команд**: `GET/POST /api/commands`, `GET/PUT/DELETE /api/commands/[id]`
  - Валидация имени (латиница, цифры, _ и -, без /)
  - Валидация type (text/faq/function)
  - Логируется в audit: `command_create`, `command_update`, `command_delete`
- ✨ **Endpoint `POST /api/commands/register-all`** — bulk регистрация всех enabled команд в MAX через PATCH /me
  - Логируется как `commands_register` с количеством
- ✨ **Endpoint `POST /api/commands/reorder`** — bulk update order в транзакции
- ✨ **Seed 8 стандартных команд**:
  - `/start` (function) — главное меню
  - `/help` (function) — справка
  - `/menu` (function) — показать категории
  - `/search <text>` (function) — поиск по базе знаний с аргументом
  - `/show <faqId>` (function) — показать конкретный ответ по ID
  - `/about` (text) — о программе
  - `/contacts` (text) — контакты федеральной команды
  - `/faq` (function) — список всех вопросов с /show ссылками
- ✨ **Команды с аргументами** в bot-logic.ts:
  - `/search регистрация` → поиск по фразе "регистрация"
  - `/show abc123` → показать конкретный FAQ по ID
  - Парсинг: `/name arg1 arg2 ...` → name = "name", args = "arg1 arg2 ..."
- ✨ **Fallback для неизвестных команд**: `/unknown` → список всех доступных команд
- ✨ **UI управления командами** (commands-panel.tsx) в разделе "Настройки":
  - Таблица с колонками: №, команда (с /), описание, тип, активна, порядок, действия
  - Создание/редактирование через диалог с динамическими полями (text → textarea, faq → select)
  - Подсказка со списком встроенных функций для type=function
  - Кнопки вверх/вниз для упорядочивания
  - Переключатель enabled для каждой команды
  - Кнопка "Зарегистрировать все в MAX" — отправляет все enabled команды в MAX
- ✨ **Расширение audit-view** — добавлены лейблы для command_create/update/delete, audit_export

  - `formatDurationMs(ms)` — длительность в человекочитаемом формате

- Health endpoint возвращает `version: "1.2"`

### Исправлено
- 🐛 **Off-topic фильтр** — был слишком лояльный, почти любой запрос со словами "программа"/"помощь"/"проект" считался programme-related
  - Заменён на двухуровневую систему:
    - `STRONG_TERMS` — уникальные для программы слова (служение, добро.рф, росмолодёж, etc.) — одно совпадение = on-topic
    - `WEAK_TERMS` — общие образовательные слова (педагог, наставник, школ, etc.) — нужно ≥2 совпадений
  - Проверено на тестах: "какая погода в Москве" → off_topic, "помогите зарегистрироваться на программе" → search
- 🐛 **Поиск FAQ** (`searchFaq` в `bot-logic.ts`):
  - Добавлены STOPWORDS (русские и английские предлоги/местоимения: и/а/но/что/the/a/...)
  - Минимальная длина слова 3 символа (было 2)
  - Бонус 1.5× за совпадение в поле keywords (более релевантно)
- 🐛 Убран неиспользуемый sync `getClientIp` в `lib/admin-log.ts`
- 🐛 Убраны лишние eslint-disable в dialog-компонентах

### Добавлено — расширенное логирование и аналитика

#### Новые поля MessageLog (+7):
- `source` — тип ответа: `system` | `command` | `callback` | `search` | `faq` | `llm` | `fallback` | `off_topic`

- ✨ **"Аналитика"** (analytics-view.tsx) — воронка обработки, метрики конверсии, график активности (часы/дни/недели), переключатель периода, топ запросов/разделов/ответов, время отклика (avg/p95/min/max), распределение по источникам, последние ошибки MAX API

## [1.0] — 2026-09-24

### Добавлено — первоначальный релиз

#### Бот для пользователей MAX:
- Webhook endpoint `POST /api/max/webhook` для приёма событий от MAX Bot API
- Обработка `update_type`: `bot_started`, `message_callback`, `message_created`
- Inline-кнопки для навигации по категориям
- Полнотекстовый поиск по базе FAQ (по вопросам, ответам, ключевым словам)
- ИИ-ассистент на базе z-ai-web-dev-sdk (LLM-fallback)
- Off-topic фильтр
- Команды `/start` и `/help`
- Регистрация команд в MAX через PATCH /me

#### Админ-панель (5 разделов):
- **Дашборд**: счётчики (категории, FAQ, пользователи, сообщения), график активности за 7 дней, топ просматриваемых ответов, последние обратившиеся пользователи
- **Категории**: CRUD с авто-генерацией slug, переключатель публикации, счётчик элементов
- **База знаний (FAQ)**: фильтр по категории, полнотекстовый поиск, CRUD, ключевые слова
- **Логи обращений**: журнал всех входящих/исходящих сообщений с фильтрами и пагинацией
- **Настройки**: подключение бота (токен), webhook URL с подпиской, тексты приветствия/справки, тестовая отправка сообщений, встроенная инструкция для сотрудников

#### База данных (5 моделей):
- `Category` — тематические разделы FAQ
- `FaqItem` — вопросы и ответы
- `MaxUser` — пользователи MAX, общающиеся с ботом
- `MessageLog` — логи всех сообщений (входящие/исходящие)
- `BotSetting` — настройки бота (key-value)

#### Seed-данные:
- 6 категорий: О программе, Регистрация, Документы, Платформы, Социальные проекты, Контакты
- 23 типовых вопроса с ответами и ключевыми словами

#### Безопасность:
- Cookie-аутентификация админ-панели (httpOnly, 7 дней)
- Токен бота хранится в БД, не экспортируется в JSON-бэкап
- Все admin API роуты требуют авторизации

#### Экспорт/импорт:
- CSV-экспорт логов обращений с фильтрами
- JSON-бэкап базы знаний (экспорт/импорт)
- Регистрация команд бота в MAX

#### Технологии:
- Next.js 16 (App Router) + TypeScript 5
- Prisma ORM + SQLite
- shadcn/ui + Tailwind CSS 4
- z-ai-web-dev-sdk (backend only)
- MAX Bot API — `https://platform-api2.max.ru/`
