## 🚀 Быстрый старт

**Если вы разворачиваете впервые:**
1. Прочитайте [DEPLOYMENT.md](./DEPLOYMENT.md) → раздел "Локальный запуск"
2. Установите зависимости: `bun install`
3. Настройте базу: `bun run db:push && bun run scripts/seed.ts`
4. Запустите: `bun run dev` → http://localhost:3000
5. Пароль по умолчанию: `admin123` (смените в `.env`)

**Если вы сотруд программы и наполняете базу:**
1. Прочитайте [STAFF_GUIDE.md](./STAFF_GUIDE.md) → "С чего начать"
2. Зайдите в админку под логином, который дал администратор
3. Откройте раздел "База знаний" → "Добавить ответ"
4. Следуйте [инструкции по написанию FAQ](./FAQ_WRITING.md)

**Если вы пользователь бота в MAX:**
1. Откройте [USER_GUIDE.md](./USER_GUIDE.md)
2. Найдите бота по никнейму в MAX
3. Нажмите "Начать диалог"
4. Следуйте подсказкам бота

## 📋 Обзор проекта

### Назначение
Чат-бот в национальном мессенджере **MAX** для информационной поддержки участников просветительской программы "Обучение служением. Первые" — социальная задача №4262 от Ассоциации Добро.рф.

### Целевая аудитория
- **Основная**: педагоги и представители образовательных организаций, участвующих в программе
- **Дополнительная**: региональные команды, специалисты федеральной команды

### Ключевое требование ТЗ
> Возможность дальнейшего бесплатного или не требующего специальных навыков обновления базы ответов сотрудниками программы без постоянного привлечения разработчиков.

✅ **Реализовано**: визуальная админ-панель с CRUD для категорий и ответов, встроенная инструкция, прямое добавление запросов без ответа в базу.

### Технологии
- **Backend**: Next.js 16 (App Router) + TypeScript 5
- **База данных**: Prisma ORM + SQLite (6 моделей)
- **Frontend**: shadcn/ui + Tailwind CSS 4
- **ИИ-фолбэк**: z-ai-web-dev-sdk (языковая модель, backend only)
- **Интеграция**: MAX Bot API — `https://platform-api2.max.ru/`
