## Принципы хорошего FAQ

### 1. Краткость — сестра таланта

Пользователь в мессенджере не хочет читать "Войну и мир". Оптимальный объём ответа:
- **50-200 слов** для простых вопросов
- **200-400 слов** для сложных (с инструкциями)
- **Больше 400 слов** — разделите на несколько ответов

### 2. Понятность

- Без канцелярита
- Без лишних терминов
- Если термин нужен — объясните его
- Используйте "вы", а не "пользователь" / "заявитель"

✅ "Зарегистрируйтесь на платформе dobro.ru"
❌ "Пользователю необходимо произвести регистрацию на цифровой платформе"

### 3. Точность

- Конкретные даты, ссылки, имена — дважды проверены
- Не "скоро", а "до 31 декабря 2026 года"
- Не "платформа", а "dobro.ru"
- Если информация может измениться — отметьте срок действия

### 4. Действие

Каждый ответ должен вести к действию:
- "Скачайте шаблон по ссылке..."
- "Отправьте заявку на info@dobro.ru"
- "Перейдите в раздел X"
- "Свяжитесь с региональным координатором"

Не просто "информация", а "что делать".

### 5. Честность

Если не знаете — скажите:
> Точной информации по этому вопросу в базе знаний нет. Свяжитесь с федеральной командой через info@dobro.ru.

Лучше так, чем выдумывать.

## Структура ответа

### Базовая формула

```
[ЧТО] — короткий ответ на вопрос, 1-2 предложения.

[КАК] — пошаговая инструкция или детали.

[СРОК/ИСТОЧНИК] — когда, где, ссылки.
```

### Пример: вопрос "Как зарегистрироваться?"

✅ **Хороший ответ:**
```
Чтобы зарегистрироваться на программе "Обучение служением. Первые", подайте заявку на платформе Добро.рф.

Что нужно сделать:
1. Создайте аккаунт на dobro.ru или войдите через ЕСИА (Госуслуги).
2. В разделе "Обучение служением" нажмите "Подать заявку".
3. Заполните данные образовательной организации и контактного педагога.
4. Подтвердите заявку — она появится в личном кабинете.

Срок рассмотрения — до 5 рабочих дней. Уведомление придёт на email и в личный кабинет.
```

❌ **Плохой ответ:**
```
Для регистрации необходимо посетить платформу и заполнить форму.
```

### Структура со списком

Если ответ содержит перечисление — используйте списки через "•" или нумерацию "1."

✅ **Хорошо:**
```
Для участия нужны следующие документы:
• Заявка педагога на платформе dobro.ru
• Согласие родителей (для несовершеннолетних)
• Согласие на обработку персональных данных

Шаблоны согласий доступны в личном кабинете.
```

❌ **Плохо:**
```
Для участия нужны заявка педагога на платформе dobro.ru согласие родителей для несовершеннолетних и согласие на обработку персональных данных шаблоны согласий доступны в личном кабинете.
```

### Структура с этапами

Если есть порядок действий — нумеруйте:

✅ **Хорошо:**
```
Процесс подачи отчёта:

1. Откройте личный кабинет на dobro.ru.
2. Перейдите в раздел "Мои проекты" → выберите проект.
3. Нажмите "Загрузить отчёт".
4. Заполните итоговую анкету.
5. Прикрепите проектный продукт (презентация/видео/документация).
6. Нажмите "Отправить".

Срок сдачи — до 31 декабря 2026 года.
```

## Вопросы: как формулировать

### Используйте форму вопроса

✅ "Как зарегистрироваться?"
❌ "Регистрация"

✅ "Какие документы нужны?"
❌ "Документы"

✅ "Что такое социальное служение?"
❌ "Социальное служение"

### Формулируйте как пользователь

Используйте живой язык — как люди обычно спрашивают.

✅ "Как зарегистрироваться на программе?" (так спросит педагог)
❌ "Процедура регистрации участника программы" (так спросит чиновник)

### Делайте вопрос конкретным

✅ "Какие документы нужны для участия в программе?"
❌ "Что нужно?" (непонятно, что именно)

✅ "В какие сроки реализуется программа?"
❌ "Когда?" (слишком общо)

### Один вопрос — один ответ

Не объединяйте несколько вопросов в один.

❌ "Как зарегистрироваться и какие документы нужны?"
✅ Раздельной на два: "Как зарегистрироваться?" + "Какие документы нужны?"

## Ключевые слова

Ключевые слова — **самое важное поле** в FAQ. От него зависит, найдёт ли бот ваш ответ.

### Что писать

Все синонимы и варианты формулировки вопроса:

Для вопроса "Как зарегистрироваться?":
```
регистрация, как зарегистрироваться, как вступить, как присоединиться, заявка, подать заявку, создание аккаунта, вход, есиа, госуслуги, личный кабинет, новый пользователь, первый вход, начать участие, стать участником
```

### Как выбирать

Подумайте: как ещё пользователь может сформулировать вопрос?
- Другими словами-синонимами (встать, присоединиться, начать)
- С ошибками (регестрация, ригистрация — варианты с опечатками)
- На сленге (как войти, как попасть)

### Что не нужно

- Стоп-слова (и/а/но/что/как/the/a/...) — бот игнорирует
- Короткие слова (< 3 символов) — игнорируются
- Одно слово в единственном числе — мало, добавьте синонимы

### Пример: хорошо vs плохо

✅ **Хорошо** (для вопроса "Как связаться с федеральной командой?"):
```
связаться, контакт, федеральная команда, почта, email, поддержка, техподдержка, помощь, оператор, написать, задать вопрос, обратиться, координатор, контактный email
```

❌ **Плохо**:
```
контакты
```

Бот не найдёт ответ, если пользователь спросит "как написать в команду?".

## Примеры: хорошее vs плохое

### Пример 1. Простой вопрос

**Вопрос:** "Что такое программа "Обучение служением. Первые"?"

✅ **Хороший ответ:**
```
"Обучение служением. Первые" — это просветительская программа, цель которой — развитие у обучающихся навыков проектной деятельности через социальное служение.

Педагоги и образовательные организации реализуют социальные проекты совместно с социальными партнёрами — организациями, у которых есть реальные задачи.

Программа объединяет образовательную и социальную повестку: школьники и студенты получают практический опыт, а некоммерческие организации и инициативы — реальную помощь.
```

Ключевые слова: `программа, обучение служением, первые, что такое, описание, цель, для чего, о чём, рассказать о программе`

❌ **Плохой ответ:**
```
Это просветительская программа.
```

### Пример 2. С инструкцией

**Вопрос:** "Как оформить отчёт по проекту?"

✅ **Хороший ответ:**
```
Отчётность по проекту включает три шага:

1. Заполните итоговую анкету в личном кабинете на платформе Добро.рф.
2. Загрузите проектный продукт — формат зависит от типа задачи:
   • Презентация (.pdf)
   • Видеоролик (.mp4, до 200 MB)
   • Методическое пособие (.docx)
3. Заполните рефлексивный лист обучающихся (шаблон в личном кабинете).

Сроки сдачи отчётности указаны в карточке социальной задачи.

При проблемах с загрузкой — обратитесь в техподдержку через форму обратной связи на dobro.ru.
```

Ключевые слова: `отчёт, анкета, рефлексия, итоговая аттестация, сдача, проектный продукт, презентация, видеоролик, методичка, шаблон отчёта, как сдать, что сдавать`

❌ **Плохой ответ:**
```
Нужно заполнить анкету и загрузить материалы.
```

### Пример 3. Со ссылками и контактами

**Вопрос:** "Как связаться с федеральной командой программы?"

✅ **Хороший ответ:**
```
Связаться с федеральной командой можно через:

• Электронная почта: info@dobro.ru (в теме письма укажите "Обучение служением")
• Форма обратной связи на платформе Добро.рф
• Этот чат-бот в мессенджере MAX — для типовых вопросов

Срок ответа:
• Через email — до 3 рабочих дней
• Через форму на платформе — до 5 рабочих дней

Если ваш вопрос срочный — обязательно укажите это в теме письма.
```

Ключевые слова: `связаться, контакты, федеральная команда, почта, email, поддержка, техподдержка, помощь, оператор, написать, задать вопрос, обратиться, координатор, контактный email,_info@dobro.ru, асв, ассоциация добро.рф`

❌ **Плохой ответ:**
```
Напишите на info@dobro.ru.
```

### Пример 4. Несколько путей решения

**Вопрос:** "Что делать, если платформа работает некорректно?"

✅ **Хороший ответ:**
```
Если столкнулись с технической ошибкой на платформе Добро.рф:

1. Обновите страницу и попробуйте снова.
2. Очистите кэш браузера или попробуйте другой браузер.
3. Если ошибка повторяется — обратитесь в техподдержку:
   • Через форму обратной связи на dobro.ru (раздел "Помощь" → "Техническая поддержка")
   • По электронной почте info@dobro.ru

В обращении обязательно укажите:
• Описание проблемы
• Скриншот ошибки
• Время возникновения
• Ваш регион
• Ваш MAX user_id (если есть)
```

Ключевые слова: `не работает, ошибка, техподдержка, поддержка, bug, баг, не загружается, не отправляется, не открывается, платформа, dobro, сайт, страница не отвечает, ошибка 500, ошибка 404`

❌ **Плохой ответ:**
```
Обратитесь в техподдержку.
```

## Чек-лист перед публикацией

Перед тем как нажать "Создать" или "Сохранить" — проверьте:

- [ ] **Вопрос** сформулирован как вопрос (с вопросительным знаком)
- [ ] **Вопрос** конкретный (можно понять, о чём речь)
- [ ] **Ответ** отвечает на вопрос (а не на другой)
- [ ] **Ответ** содержит конкретные шаги / ссылки / даты
- [ ] **Ответ** без орфографических ошибок
- [ ] **Ответ** не длиннее 400 слов (если длиннее — разделить)
- [ ] **Ключевые слова** заполнены (минимум 5-10 синонимов)
- [ ] **Ключевые слова** включают варианты с опечатками
- [ ] **Категория** выбрана правильно
- [ ] **Опубликовано** включено (зелёный переключатель)
- [ ] Проверили в боте — найдётся ли ответ по вашему вопросу

### Как проверить в боте

После сохранения:
1. Откройте бота в MAX
2. Отправьте свой вопрос текстом
3. Бот должен показать ваш ответ в кнопках (или сразу)

Если не находит — добавьте больше ключевых слов или измените формулировку вопроса.

## Дополнительные советы

### Используйте эмодзи умеренно

Один эмодзи в начале — добавит визуального акцента. Больше — выглядит непрофессионально.

✅ "📋 Раздел: Регистрация и участие"
❌ "📋 🔥 🚀 Регистрация и участие 🎯 ✨ 💥"

### Делайте акценты через заглавные

Если нужно выделить важное — используйте ЗАГЛАВНЫЕ или *звёздочки*:
- "ВАЖНО: заявка подаётся до 31 декабря"
- "Срок: *3 рабочих дня*"

### Повторяйте главное

Если важная информация (сроки, контакты) — повторите в разных местах ответа. Пользователь может пропустить.

### Не бойтесь длинных ответов

Если вопрос сложный (например, отчётность по проекту) — лучше написать подробно, чем кратко и непонятно.

### Обновляйте при изменениях

Если в программе что-то изменилось (новые документы, сроки, контакты) — отредактируйте ответ. Старые данные вреднее, чем отсутствие данных.

### Смотрите, что спрашивают

Раз в неделю открывайте раздел "Запросы без ответа" (см. [STAFF_GUIDE.md](./STAFF_GUIDE.md)). Если один и тот же вопрос задают 2+ раза — добавьте ответ.

